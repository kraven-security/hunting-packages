# Massive Global Takedown: 20-Year-Old Sality Botnet Finally Disrupted

CrowdStrike, in collaboration with international law enforcement and industry partners, executed a coordinated peer-to-peer sinkholing operation to successfully disrupt the Sality botnet. This global takedown isolated infected machines and rendered the criminal infrastructure's decentralized command channel completely inert.

Key takeaways:

**🎯 Target**: The Sality botnet successfully compromised over 15,000 machines worldwide. Operators targeted these global machines to distribute a wide variety of malicious payloads, including credential theft, spam distribution, proxy services, and network exploitation tools.

**💡 Insight**: Sality remained a persistent threat for over two decades due to its highly resilient peer-to-peer (P2P) architecture that lacked a single point of failure. Furthermore, it operated as a polymorphic file infector that continuously regenerated by attaching itself to executables and spreading through network shares, removable drives, and file sharing.

**☑️ Recommendation 1**: Organizations should secure network shares and strictly control the use of removable drives. Because Sality and similar polymorphic file infectors exploit these file-sharing vectors, limiting access prevents the malware from continuously regenerating.

**☑️ Recommendation 2**: Security teams must monitor internal environments for decentralized, peer-to-peer communication patterns. Unlike traditional threats, resilient botnets like Sality do not rely on centralized command-and-control (C2) servers, making standard C2 blocking methods ineffective.

**☑️ Recommendation 3**:Organizations should implement advanced endpoint protection capable of detecting and neutralizing polymorphic file infectors. This ensures systems are safeguarded against the automated deployment of secondary payloads, which can range from credential stealers to distributed denial-of-service capabilities.
